# Chapter 1–3

본 디렉터리는 교재 1–3장의 예제, 연습문제 및 시각화 코드를 정리한 중간 작업본입니다.
현재는 최신 시각화 모듈을 적용한 코드와 기존 구형 모듈을 사용하는 코드를 구분하여
보관하고 있으며, 코드 작성 형식과 모듈 구조는 추후 단계적으로 통일할 예정입니다.

## 디렉터리 구조

```text
ch1-3/
├── picture/                 # 최신 시각화 모듈과 이를 적용한 코드
│
├── legacy/
│   ├── example/             # 구형 모듈을 사용하는 예제 코드
│   ├── exercise/            # 구형 모듈을 사용하는 연습문제 코드
│   └── modules/             # 기존 코드에서 사용하는 구형 시각화 모듈
│
└── README.md                # 현재 작업 상태 및 실행 안내
```

### `picture/`

현재 최신화된 시각화 모듈과 해당 모듈을 적용한 코드를 저장합니다.

현재 단계에서는 코드의 실행 가능성과 중간 결과 확인을 우선하여 최신 모듈과 이를
사용하는 코드를 같은 디렉터리에 둡니다. 향후 진행 방향에 따라 바뀔 수 있습니다.

### `legacy/example/`

기존 시각화 모듈을 사용하여 작성한 교재 예제 코드를 저장합니다.

현재 작성된 코드의 동작을 보존하기 위한 영역이며, 추후 최신 시각화 모듈과 통일된
코드 작성 형식에 맞추어 수정할 예정입니다.

### `legacy/exercise/`

기존 시각화 모듈을 사용하여 작성한 연습문제 코드를 저장합니다.

현재 작성된 코드의 동작을 보존하기 위한 영역이며, 추후 최신 시각화 모듈과 통일된
코드 작성 형식에 맞추어 수정할 예정입니다.

### `legacy/modules/`

`legacy/example/` 및 `legacy/exercise/`의 기존 코드에서 사용하는 구형 시각화 모듈을 보관합니다.

구형 모듈은 기존 코드의 실행을 유지하기 위해 현재 상태로 보존하며, 이후 최신 모듈
구조에 맞추어 기능을 정리하고 통합할 예정입니다.

## 코드 실행

현재 일부 코드는 모듈 구조와 import 방식이 아직 통일되지 않았습니다.

따라서 현재 단계에서는 실행할 Python 코드가 사용하는 모듈 파일을 코드와 같은 위치에 두고 실행합니다.

예를 들어 picture_1.1.py를 실행하려는 경우
```
picture_1.1.py
plot_tools_diffgeo.py
```
가 동일 위치에 존재해야 합니다.

## 현재 개발 상태

요청받은 내용에 따라 기존 그림이 있는 대상에 대한 코드를 작성하였습니다.

legacy 내의 코드는 과거 그림이 없는 예제, 연습문제에 대해 작성하였던 코드입니다.
아직 최신화가 반영되지 않아 lagacy/modules 의 코드를 통해 실행시킬 수 있습니다.
