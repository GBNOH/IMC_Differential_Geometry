# SRC Differential Geometry

기존 교재의 Mathematica 구현을 Python으로 이관하고, 미분기하학의 주요 기하적
대상을 시각화하는 학부 수준의 코드북 프로젝트입니다. 교재의 수학적 내용과 기존
구현 의도를 유지하면서 Python 기반의 계산 및 대화형 2D·3D 시각화로 재구성하는
것을 목표로 합니다.

본 과제의 최종 개발 산출물은 표준화된 `.py` 소스코드이며, GitHub 탑재를 필수
과업으로 합니다.

## 프로젝트 목표

- 교재에 수록된 Mathematica 구현을 재현 가능한 Python 코드로 이관합니다.
- 기존 구현의 수식, 매개변수와 시각화 의도를 가능한 한 보존합니다.
- 곡선과 곡면을 대화형 2D·3D 그래프로 시각화합니다.
- 기호 연산과 수치 계산을 연결하여 수식의 기하적 의미를 설명합니다.
- 공통 기능을 모듈화하여 챕터별 코드의 중복을 줄입니다.
- 2009–2026학년도 교원임용시험 관련 미분기하학 문제와 시각화 자료를 제공합니다.
- 연구 보고서 작성에 활용할 수 있는 코드와 결과물을 체계적으로 관리합니다.

## 기술 스택

프로젝트에서 사용하는 기본 라이브러리는 다음과 같습니다.

| 라이브러리 | 용도 |
|---|---|
| NumPy | 배열 처리와 수치 계산 |
| Plotly | 대화형 2D·3D 시각화 |
| SciPy | 과학 계산과 수치해석 |
| SymPy | 수식의 기호 연산 |
| Geomstats | 미분기하학과 리만기하학 계산 |

신규 시각화는 Plotly를 기본으로 작성합니다. 위 목록에 없는 라이브러리가 필요한
경우에는 도입 목적과 활용 범위를 팀에 공유한 후 결정합니다.

> 현재 루트의 `main.py`는 Matplotlib으로 작성된 초기 예제입니다. 프로젝트의
> 라이브러리 기준에 맞추려면 추후 Plotly 기반 코드로 변경하거나 적절한 예제
> 디렉터리로 이동해야 합니다.

## GitHub와 Google Drive 운영

프로젝트는 GitHub와 Google Drive를 함께 사용하는 투트랙 방식으로 운영합니다.

### GitHub

GitHub를 소스코드의 기준 저장소로 사용합니다.

- 표준화된 `.py` 소스코드
- 공통 모듈과 설정 파일
- 프로젝트 및 디렉터리별 README
- 코드 변경 이력과 Pull Request
- 재현에 필요한 소규모 예제 데이터

### Google Drive

Google Drive는 교수 및 연구진의 확인과 결과물 관리를 위한 공유 공간으로 사용합니다.

- 연구 및 제출 보고서
- 회의 자료와 행정 문서
- 발표 자료
- 용량이 큰 이미지, 동영상 및 중간 결과물
- 교수 및 연구진 검토용 결과물

동일한 소스코드를 GitHub와 Google Drive에서 각각 수정하지 않습니다. 코드의 최신
버전은 GitHub를 기준으로 하며, Google Drive에는 필요한 결과물이나 검토용 사본을
제공합니다. Google Drive 링크와 관리 담당자는 확정 후 이 문서에 추가합니다.

## 개발 환경 구성

Python의 최소 지원 버전은 팀 협의를 거쳐 확정할 예정입니다.

저장소를 복제하고 프로젝트 디렉터리로 이동합니다.

```powershell
git clone https://github.com/GBNOH/SRC_Differential_Geometry.git
cd SRC_Differential_Geometry
```

가상환경을 생성하고 활성화합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

현재 기본 라이브러리는 다음과 같이 설치할 수 있습니다.

```powershell
python -m pip install --upgrade pip
pip install numpy plotly scipy sympy geomstats
```

의존성 버전이 확정되면 루트의 `requirements.txt` 또는 `pyproject.toml`을 기준으로
설치하도록 변경합니다.

## 코드 작성 원칙

- 최종 산출물은 실행 가능한 `.py` 파일로 작성합니다.
- 파일명은 내용을 알 수 있는 영문 `snake_case`를 사용합니다.
- 코드 상단에 구현한 개념, 주요 수식과 실행 결과를 설명합니다.
- 수식의 기호와 코드의 변수명은 가능한 한 일관되게 사용합니다.
- 3D 시각화는 Plotly를 기본으로 사용합니다.
- 반복되는 계산, 좌표 변환 및 시각화 기능은 `modules/`로 분리합니다.
- 공통 모듈을 수정할 때는 이를 사용하는 다른 챕터에 미치는 영향을 확인합니다.
- 실행 코드에는 가능한 한 `main()` 함수와 다음 진입점을 사용합니다.

```python
def main():
    """계산과 시각화를 실행합니다."""
    pass


if __name__ == "__main__":
    main()
```

## Git 작업 방법

작업 전 `main` 브랜치를 최신 상태로 갱신하고 작업 브랜치를 생성합니다.

```powershell
git switch main
git pull --ff-only origin main
git switch -c feature/<작업명>
```

변경 사항을 확인하고 커밋한 후 원격 저장소에 올립니다.

```powershell
git status
git add <변경한_파일>
git commit -m "<변경 내용을 설명하는 메시지>"
git push -u origin feature/<작업명>
```

GitHub에서 Pull Request를 생성하여 변경 내용을 확인한 후 `main` 브랜치에
병합합니다. 팀 협의 없이 다른 담당자의 파일을 대규모로 이동하거나 이름을
변경하지 않습니다.
